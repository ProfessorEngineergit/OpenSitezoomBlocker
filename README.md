# 🚫 OpenSiteBlocker

Eine moderne Web-Anwendung zum Generieren von personalisierten HTML-Code-Snippets, die verschiedene Website-Funktionen blockieren können.

## 🌟 Features

- **📝 Text-Auswahl blockieren** - Verhindert das Markieren von Text
- **🔍 Seiten-Zoom blockieren** - Deaktiviert das Zoomen der Seite
- **📜 Scrollen blockieren** - Verhindert das Scrollen auf der Seite
- **🖱️ Rechtsklick blockieren** - Deaktiviert das Kontextmenü
- **📋 Kopieren blockieren** - Verhindert das Kopieren von Inhalten
- **✂️ Ausschneiden blockieren** - Verhindert das Ausschneiden von Inhalten
- **📌 Einfügen blockieren** - Verhindert das Einfügen von Inhalten
- **👆 Drag & Drop blockieren** - Deaktiviert Drag & Drop-Funktionalität
- **🖨️ Drucken blockieren** - Verhindert das Drucken der Seite
- **🔧 DevTools blockieren** - Versucht Entwicklertools zu blockieren

## 🎨 Design

- **Glassmorphism Design** - Modernes, glasartiges Interface mit Blur-Effekten
- **Light & Dark Mode** - Umschaltbare Themes für verschiedene Lichtverhältnisse
- **Responsive** - Optimiert für Desktop, Tablet und Mobile
- **Benutzerfreundlich** - Intuitive Toggle-Schalter für jede Funktion

## 🚀 Verwendung

1. Öffne `index.html` in einem Browser
2. Wähle die Funktionen aus, die du blockieren möchtest
3. Der Code wird automatisch generiert
4. Klicke auf "Code kopieren" um den Code in die Zwischenablage zu kopieren
5. Füge den Code in den `<head>`-Bereich deiner HTML-Datei ein

## 💻 Technologie

- Pure HTML5
- CSS3 mit Glassmorphism-Effekten
- Vanilla JavaScript (keine Abhängigkeiten)
- LocalStorage für Theme-Speicherung

## 📦 Installation

Keine Installation erforderlich! Einfach die Dateien herunterladen und `index.html` öffnen.

## 🌐 Live Demo
