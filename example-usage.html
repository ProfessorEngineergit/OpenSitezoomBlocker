About This Example

This is an example page showing how the generated code from OpenSiteBlocker works in practice. The blocking code is inserted in the <head> section and automatically protects your content from common interactions.

How to Use

  1. Open index.html in your browser
  2. Select the features you want to block using the toggles
  3. Click "Code kopieren" to copy the generated code
  4. Paste the code into your website's <head> section
  5. Your website is now protected!

Disclaimer

These blocking features should be used responsibly. Blocking too many features can harm the user experience and accessibility of your website. Always consider your users' needs and accessibility requirements before implementing these protections.
